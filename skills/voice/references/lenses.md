# Lenses for a review pass

Use these when reviewing copy someone else drafted, after the writing guard has passed it. The person's own messages outrank every lens: a lens that flags their real register is wrong about them.

## Checks worth running

1. Flag clusters, not single tells. One fragment, one lowercase heading or one dropped apostrophe may be their voice. Three tells in one paragraph is a draft that went generic.
2. Opinions are voice; facts are not. Never add a name, number, date, quote or citation the source lacks, and never round a number.
3. Portability. If the sentence could sit unchanged on another product's site or in another person's email, cut it.
4. The brief is not the artifact. Words that address the writer ("keep it terse", "make it feel local") are a bug when they reach the output.
5. Sentence load. Every sentence carries a claim, number, mechanism, name, consequence or tradeoff. If deleting it only removes rhythm, delete it.
6. Paraphrase. Restate the line plainly; if the plain version is better, ship that. If it boils down to "stuff exists" or "things are changing", delete it.
7. Sameness. Parallel fragments that mirror too tidily, colon-then-list runs and identical sentence shapes read as generated. The tell is uniformity.
8. Plain where plain helps. Errors, setup steps, support and reference copy stay neutral and specific; personality there is friction.
9. Structure is a decision. Headings and bullets earn their place in reference copy and get in the way of an argument.

## How a pass runs

One finder per lens over the copy, then dedupe by file and quote and count how many lenses hit each spot. Two judges per file, one leaning toward the person's voice and one toward catching generic prose, and both must approve a change. One builder per file applies the approved changes as written. The report lists what was applied and what was rejected, one line each, so the person can overrule it.

Third-party anti-slop skills make useful finders, but most of them flag fragments, force sentence case or push for anecdotes, which flattens a terse voice. Read their prose rules, and never run scripts they ship without reading them first.
